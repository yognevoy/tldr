# tldr

`tldr` is an agent skill that forces terse, high-signal responses.

1. **Answer First** — Lead with the Conclusion, Skip the Acknowledgment.
2. **Cut the Padding** — No Long Intros, Drop Detail That Does Not Change the Decision, No Trailing Summary.
3. **Stay Under the Limit** — Two Paragraphs Hard Cap, Lists Over Prose Sparingly, When the User Explicitly Asks for More.

## Installation

Copy `SKILL.md` into your agent's skills directory as `tldr/SKILL.md` (for example `~/.claude/skills/tldr/SKILL.md`, `~/.cursor/skills/tldr/SKILL.md`, or `~/.grok/skills/tldr/SKILL.md`), then invoke `/tldr`.
